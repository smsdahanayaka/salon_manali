# Salon Manali Website — Project Workspace

This workspace holds the research, planning, and documentation for a
**speculative pitch website for Salon Manali (Devinuwara, Matara)**. The
process is deliberately: **research first, plan carefully, then design.**

⚠️ **This is not a commissioned project.** There has been no contact with
the salon owner yet — the plan is to build a compelling demo site first,
then present it to the owner, and only proceed as a real engagement if they
agree to buy it. See [memory/salon-manali.md](memory/salon-manali.md) §0 and
[planning/pitch-strategy.md](planning/pitch-strategy.md) before assuming
anything here reflects confirmed client requirements — it doesn't; it
reflects the user's own working decisions for the pitch.

## How this is organized

- **[memory/salon-manali.md](memory/salon-manali.md)** — the single source
  of truth for what we know: the project's real nature (§0), brand,
  services, target customers, constraints, open questions for eventual
  outreach, and a running decisions log. Read this first in any new session
  on this project.

- **research/** — competitor and market research, feeding into planning:
  - [competitor-research.md](research/competitor-research.md) — named local
    (Matara/Devinuwara/Galle) and Sri Lanka-wide competitors, including an
    important naming-confusion issue with other salons also called "Salon
    Manali"
  - [trends-and-inspiration.md](research/trends-and-inspiration.md) — modern
    salon website design patterns worldwide
  - [industry-findings.md](research/industry-findings.md) — Sri Lankan
    bridal salon market context and general best practices

- **planning/** — how research turns into a buildable pitch demo:
  - [pitch-strategy.md](planning/pitch-strategy.md) — **read this one
    early** — the sales case to lead with, the placeholder-vs-real content
    rules, and what "done" means for a demo nobody has bought yet
  - [site-structure.md](planning/site-structure.md) — sitemap/pages
  - [features-and-content.md](planning/features-and-content.md) — features
    mapped to goals, and what's placeholder now vs. needed from the real
    owner later
  - [roadmap.md](planning/roadmap.md) — phased process roadmap: Research →
    Build the demo → Pitch to the owner → (if accepted) real onboarding →
    launch
