# Roadmap

Process roadmap for this project: **research first, plan carefully, then
design.** Note the project model is **speculative pitch work** — we build
first and present to the salon owner afterward; see [[pitch-strategy]] and
[[salon-manali]] memory §0 for full context. That means Phase 2 below is
not "blocked on the client" — it proceeds using researched best-guesses and
clearly-marked placeholders, because there is no client relationship yet to
unblock it.
